# Website Project

A web-based project repository. This repository keeps the project source code, setup instructions, and development documentation together.

## Project status
This repository is being maintained for version control and coursework documentation.

## Main contents
- `docs/` — project overview, installation notes, user guide, and change history.
- `.github/` — templates to support issues and pull requests.
- `.gitignore` — excludes common temporary and local-only files.

## Getting started
1. Clone or download this repository.
2. Read `docs/PROJECT_OVERVIEW.md`.
3. Follow `docs/INSTALLATION.md` when setting up a local development copy.
4. Do not upload passwords, database credentials, private customer information, or production backups.

## Safety note
The documentation and GitHub support files in this pack do not run on your website. They do not modify your website's pages, database, theme, plugins, or PHP execution. Keep this pack in your GitHub repository root, separate from your live website files if you are not ready to version-control the application source.
