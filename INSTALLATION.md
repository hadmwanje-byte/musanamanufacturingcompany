# Local Installation Notes

Use these notes only when preparing a separate local development copy.

1. Keep a backup of the existing project before making changes.
2. Copy the project into your local web-server folder.
3. Create or select a development database only if the application requires one.
4. Configure local database settings using a private local configuration file.
5. Start the local web server and open the local project URL.
6. Test the pages and forms on the local copy.

## Important
Do not replace files on a live website while following these notes. Do not commit database passwords or private configuration files to GitHub. Confirm the actual project requirements before creating or changing a database.
