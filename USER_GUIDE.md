# User Guide

## Visiting the website
1. Open the website address in a browser.
2. Use the navigation menu to move between pages.
3. Read the information presented on each page.
4. Use forms only for their stated purpose.
5. Use the contact details published by the organisation when further assistance is needed.

## Administration
If the website includes an administration area, access should be limited to authorised users. Use the website's documented sign-in process and sign out after completing administrative work.

## Updating this guide
Replace these general instructions with steps that match the final website features.
